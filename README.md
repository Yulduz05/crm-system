# ApexCRM • Korporativ Savdo va Mijozlar Boshqaruvi Tizimi

Kompaniyalar va savdo bo'limlari uchun zamonaviy, qorong'i dizayndagi (Dark Space & Glassmorphism) professional CRM boshqaruv tizimi.

![ApexCRM Preview](assets/images/manager1.jpg)

## 📌 Asosiy Xususiyatlar

- **Desktop Workstation Layout**: Qat'iy 1440px o'lchamli qulay korporativ boshqaruv paneli (Foydalanuvchi talabiga asosan responsive bo'lmagan, qat'iy ekran nisbatida saqlanadi).
- **Asosiy KPI Ko'rsatkichlari**:
  - Jami Savdo Tushumi ($184,520)
  - Faol Bitimlar (64 ta)
  - Yangi Lidlar & Konversiya (382 ta lid, 32.8% konversiya)
  - Mijozlar Qoniqishi (CSAT: 98.6%)
- **Savdo Dinamikasi Grafigi**: Interaktiv SVG Area chart va oylik daromad dinamikasi.
- **5 Bosqichli Savdo Voronkasi (Pipeline Funnel)**: Lidlar kelib tushishi, aloqa, tijorat taklifi, shartnoma va g'alaba.
- **Mijozlar Bazasini Boshqarish**:
  - Qidiruv va statuslar bo'yicha filtrlash (Yangi Lid, Muzokarada, Shartnoma, Yutildi).
  - Mas'ul menejerlar bo'yicha ajratish.
  - Yangi mijoz qo'shish (Modal oyna orqali).
  - Excel (CSV) formatida ma'lumotlarni eksport qilish.
- **Jonli Faolliklar Tarixi (Activity Feed)** va **Menejerlar Reytingi (Leaderboard)**.

## 🚀 Texnologiyalar

- **HTML5**: Semantik va toza struktura
- **CSS3**: Maxsus dizayn tizimi, CSS o'zgaruvchilari (CSS Variables), Glassmorphism va animatsiyalar
- **JavaScript**: Dinamik filtrlash, modal, jadval boshqaruvi va CSV eksport

## 💻 Loyihani ishga tushirish

Lokal serverda ishga tushirish:

```bash
# Python orqali:
python3 -m http.server 8000

# yoki brauzerda to'g'ridan-to'g'ri:
open index.html
```

Brauzerda ochish: `http://localhost:8000`
